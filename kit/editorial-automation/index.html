01

브라우저 준비

Codex에게 Chrome을 보여주세요.

ChatGPT 또는 Codex에서 브라우저 공유를 켜면, 화면을 보며 다음 버튼을 안내받을 수 있습니다. 로그인과 비밀값 입력은 대표님이 직접 합니다.

지금 할 일Codex 설정에서 Computer use를 켜고 Chrome 확장을 연결하세요.
Codex에 붙여넣기
내 브랜드 블로그에 Telegram 편집장 자동발행을 설정하려고 해. Chrome 브라우저를 보며 단계별로 한 번에 하나씩만 안내해줘. GitHub·Vercel·Telegram 화면을 열고 필요한 버튼 위치를 설명해줘. API 키, 토큰, 비밀값은 절대 채팅에 묻거나 입력하지 말고 내가 직접 입력할 수 있게만 안내해줘. 설정이 끝날 때마다 성공 여부를 확인하고 다음 단계로 넘어가줘.
02

03

Telegram + Vercel

키는 Vercel에만 보관합니다.

BotFather에서 만든 Telegram 봇과 OpenAI API 키, GitHub 토큰은 모두 Vercel Production 환경변수에 넣습니다. 코드·채팅·노션에는 적지 않습니다.

GITHUB_OWNERGITHUB_REPOGITHUB_TOKENGITHUB_WEBHOOK_SECRETTELEGRAM_BOT_TOKENOPENAI_API_KEYCRON_SECRETTELEGRAM_WEBHOOK_SECRETTELEGRAM_ADMIN_CHAT_IDEDITORIAL_APPROVAL_ENABLED=falseEDITORIAL_AUTOPUBLISH=false
주의 GITHUB_WEBHOOK_SECRET, CRON_SECRET, TELEGRAM_WEBHOOK_SECRET은 서로 다른 값으로 만드세요. Telegram 웹훅 비밀값에는 특수문자를 쓰지 않습니다.
04

연결

브라우저 버튼으로 봇을 연결합니다.

설치된 자동화에는 비밀값을 저장하지 않는 연결 페이지를 둡니다. 대표님은 그 페이지에서 CRON_SECRET을 한 번 입력하고 Telegram 연결만 누릅니다.

성공 기준“연결되었습니다. 이제 Telegram에서 봇에게 /start를 보내세요.”가 보입니다.
Codex에 붙여넣기
지금 내 배포 사이트에 Telegram 연결 페이지가 있는지 확인해줘. 없다면 비밀값을 저장하지 않는 연결 페이지와 웹훅 API를 만들어줘. 페이지에서 CRON_SECRET을 입력해 Telegram 웹훅을 한 번만 등록할 수 있게 하고, 입력값·토큰·API 키는 화면이나 로그에 절대 노출하지 마. 연결 후에는 Telegram /start로 관리자 Chat ID를 안내하고, 그 숫자를 Vercel의 TELEGRAM_ADMIN_CHAT_ID에 넣도록 한 단계씩 알려줘.
05

편집장 규칙

점수보다 먼저, 발행 금지 조건을 정합니다.

좋은 글이라도 사실·SEO·배포 조건 중 하나가 틀리면 자동 발행하지 않습니다. 점수는 통과선일 뿐입니다.

자동발행 기준90/100
  • 출처 없는 수치·효능·후기 없음
  • 정적 글·메타·FAQ·sitemap 갱신 완료
  • 내부 링크와 미리보기 배포 확인
  • 브랜드만의 실제 경험 문장 포함
Codex에 붙여넣기
이 블로그에 편집장 검수 단계를 추가해줘. 매일 07:30 한국시간에 초안을 Telegram으로 보내고, 내가 채팅으로 “도입부를 짧게”, “이 문단 삭제”처럼 수정 요청하면 같은 초안을 수정해 미리보기 링크와 점수를 다시 보내줘. 내가 10:00까지 확인하지 않으면 90점 이상이면서 모든 발행 금지 조건을 통과한 경우에만 발행해줘. 점수가 높아도 출처 없는 사실 주장, 정적 HTML·메타·sitemap·RSS·llms.txt 누락, 링크 오류, 미리보기 배포 실패가 있으면 절대 발행하지 마. 모든 초안은 먼저 검토용 PR로 만들고, 사람이 승인하면 바로 발행할 수 있게 해줘.
06

첫 테스트

가짜 초안으로 한 번만 끝까지 해봅니다.

첫날에는 실제 자동발행을 기다리지 않습니다. 테스트 초안을 보내고, 수정·점수·보류·발행 버튼이 전부 보이는지 확인합니다.

  1. Telegram에서 /status를 보내 연결 응답 확인
  2. 테스트 초안 발송 요청 → 미리보기 링크 열기
  3. “제목을 10자 줄여줘”라고 채팅 수정 요청
  4. 점수와 발행 금지 조건 확인 → 보류로 끝내기
Codex에 붙여넣기
실제 발행은 하지 말고 Telegram 편집장 시스템을 테스트해줘. 테스트 초안 하나를 검토용 상태로 만들고, Telegram에 제목·점수·미리보기 링크·보류 버튼을 보내줘. 내가 “제목을 10자 줄여줘”라고 썼을 때 수정본과 새 점수를 보내는지 확인해줘. 모든 테스트가 끝난 뒤에는 테스트 PR과 초안을 정리하거나 보류 상태로 남기고, 실제 main에는 발행하지 마.
