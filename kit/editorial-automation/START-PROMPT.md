# 실행DAY 편집장 자동발행 킷 — 시작 프롬프트

대표님은 아래 문장을 Codex 새 작업에 붙여넣고, Chrome 브라우저 공유를 켠다.

> 내 브랜드 블로그에 Telegram 편집장 자동발행을 설정하려고 해. Chrome 브라우저를 보며 단계별로 한 번에 하나씩만 안내해줘. GitHub·Vercel·Telegram 화면을 열고 필요한 버튼 위치를 설명해줘. API 키, 토큰, 비밀값은 절대 채팅에 묻거나 입력하지 말고 내가 직접 입력할 수 있게만 안내해줘. 설정이 끝날 때마다 성공 여부를 확인하고 다음 단계로 넘어가줘.

## 운영 원칙

- 비밀값은 Vercel Production 환경변수에만 넣고, 채팅·코드·문서에 남기지 않는다.
- 초안은 검토용 PR에서 시작한다.
- 매일 07:30에 초안을 알리고, 10:00에 자동발행 여부를 판단한다.
- 90점 이상만 자동발행 후보가 될 수 있으며, 사실성·정적 HTML·메타·링크·배포 검증 실패는 즉시 발행 금지다.
