# 사용자가 대화에서 확정한 편집 방향

- 평일에는 가구, 주말에는 취미·소비·재테크를 다룬다. 취미와 재테크는 방 안에 한정하지 않는다.
- 질문에 전부 답할 때까지 기다리기보다 대화와 확인된 자료로 검토용 초안을 먼저 쓴다.
- 초안을 읽고 생각과 다른 부분에 답하면 그 답변을 우선 반영해 다시 쓴다.
- 질문은 설문지 같은 말투보다 함께 글을 다듬는 동료처럼 자연스럽고 구체적인 존댓말로 쓴다. 어느 문단을 왜 묻는지 설명한다.
- 선호나 편집 제안은 사실 확인과 구분한다. 제안에 답하지 않았다고 동의했다고 기록하지 않는다.
- 사용자의 경험, 사진, 금액, 성과는 자동으로 지어내지 않는다. 자료가 부족하면 일반적인 설명으로 먼저 쓰고 필요한 경험만 질문한다.

이 문서는 현재 Codex 대화에서 확인된 선호를 정리한 것이다. 전체 대화 자동 동기화 기능은 아니다. 글별 저장 답변은 실행 시 별도로 전달된다.

## 자동 편집 선호 (2026-09-10 사용자 요청)
- 사용자는 매번 초안을 확인하기 어렵다. 작가가 답변과 검수 의견을 반영해 보완하고 SEO 검수까지 이어서 진행하기를 원한다.
- 확인 질문은 비공개 편집실에서만 보여주고 공개 본문에는 넣지 않는다.
- 사용자의 최종 역할은 텔레그램에서 발행 여부를 결정하는 것이다. AI의 검수 통과를 사용자 승인으로 기록하지 않는다.
- 이 선호는 모든 역할에 공통 적용한다. 사용자의 실제 답변과 수정 의견은 글별로 보존하며 추정된 의견을 확정된 취향으로 누적하지 않는다.
