# B01 역할 프롬프트 적용

AI-OS의 `output/editorial-agent-prompts/01-editor-in-chief.md`부터 `04-publisher.md`까지 읽고 B01 편집실에 맞춰 조정했다. 원본은 수정하지 않았다. 원본의 정의 출처는 같은 폴더의 `SOURCE-NOTES.md`를 참고했으며, 그 출처 파일 전체를 이번 작업에서 재검증한 것은 아니다.

## 적용한 내용

- 편집장: 독자의 상황·문제·핵심 주장·절별 근거를 담은 집필 지시서.
- 작가: 실제 경험과 예시 구분, 차분한 존댓말, 본문과 편집 메모 분리.
- SEO 검수: 제목과 본문 일치, 주장·출처·계산 검증, 위치별 수정문, 통과 버전.
- 발행 담당: 검수된 버전의 원고·요약·자산 묶음, 준비·예약·공개·전달 증거 구분.

## B01 맥락에 맞춘 변경

- 원본의 일·돈·AI 중심 독자를 B01의 글별 독자와 기존 브랜드 기준으로 조정했다.
- 평일 가구·주말 취미와 재테크, 주간 7개 계획·평일 초안 5개를 유지한다. 취미·재테크는 실내외 생활을 모두 포함한다.
- 정적 HTML 블로그와 runday-seo 규격, 실제 사진 선택, 사용자 승인·예약 절차를 따른다.
- 역할 요청마다 실제 파일을 읽어 실행 지시문에 넣는다. Codex와 브라우저가 같은 역할 정의를 사용한다.
- 역할 간 자동 실행을 새로 연결하지 않았다. 기존 글별 작업에는 글 ID·버전·상태를 전달하고, 일반 작업은 기존 이어서 요청 기능으로 앞선 결과를 전달한다.

다음 요청부터 적용된다. 기존 원고·답변·발행 일정·텔레그램 설정은 이 프롬프트 도입으로 바꾸지 않는다. 원격 AI-OS 앱이나 원격 텔레그램 실행기에 등록한 것은 아니다.
