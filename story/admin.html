블로그 관리

글을 쓰면 GitHub 저장소의 posts.json이 수정되고, Vercel이 자동으로 재배포합니다.

1. GitHub 토큰 만들기

  1. github.com/settings/personal-access-tokens 접속 → Generate new token 클릭
  2. Token name: 아무 이름(예: blog-admin), Expiration: 90 days
  3. Repository access: "Only select repositories" 선택 → 내 사이트 저장소만 체크
  4. Permissions → Repository permissions → Contents: Read and write로 변경
  5. 맨 아래 Generate token → 표시되는 github_pat_... 토큰을 복사 (이 화면을 벗어나면 다시 볼 수 없어요)
토큰은 이 브라우저의 localStorage에 평문으로 저장됩니다. 반드시 본인 기기·본인 브라우저에서만 사용하고, 공용 PC에서는 쓰지 마세요.
