# B01호 글감 목록

## 이야기 우선 글감

- [ ] 물건을 더 사기보다 현관 바닥을 비워보기로 한 날
- [ ] 처음 독립한 방에서 가장 오래 망설였던 가구 하나
- [ ] 작은 방이 답답해 보일 때, 꾸미기 전에 멈춰서 본 것
- [ ] 예쁜 물건보다 매일 손이 가는 물건을 고르게 된 이유
- [ ] 누군가에게 보여주기 위한 방과 내가 편한 방 사이에서 고른 것
- [ ] 좁은 집에서 포기하지 않기로 한 작은 사치
- [ ] 들이고 나서야 내 생활에 맞지 않는다고 알게 된 물건
- [ ] 수납을 늘리기 전에 물건의 자리를 정한 방법
- [ ] 반지하 생활에서 빛과 습도보다 먼저 바뀐 나의 습관
- [ ] 비어 있는 공간을 낭비가 아니라 여유로 보게 된 순간
